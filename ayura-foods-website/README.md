# Ayura Foods Website

A lightweight, responsive static website for **Ayura Foods** with a product catalog and direct WhatsApp ordering.

## Features

- Responsive mobile/desktop design
- Sesame, Groundnut and Sunflower oil product cards
- Product-specific WhatsApp order buttons
- WhatsApp QR code
- No backend required
- Ready for GitHub Pages

## Run locally

Open `index.html` in a browser, or use any simple static server.

Example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

The site is static, so no server or database is required.

## Customize

Edit:
- `index.html` for text, products and WhatsApp messages.
- `style.css` for colors/layout.
- `assets/` for product images and QR code.
